# Workout Tracker App

A mobile-friendly web app to track your muscle-building journey from 68kg to 75kg.

## Features

- **3 Workout Programs** (A: Push, B: Pull, C: Full Body)
- **Set Logging** - Track weight and reps for every set
- **Rest Timer** - Auto-starts between sets with audio/vibration alerts
- **Progress Charts** - Visualize weight gain and strength progression
- **Workout History** - Review all past workouts with details
- **Data Export/Import** - Backup your data as JSON

## How to Use

1. Open `index.html` in any web browser
2. Select a workout (A, B, or C)
3. Log your weights and reps for each set
4. Hit the checkmark when you complete a set
5. Rest timer starts automatically
6. Track your body weight in the Progress tab

## No Installation Required

This is a standalone web app that runs entirely in your browser. All data is stored locally on your device.

### To add to your phone's home screen:
1. Open the app in Safari (iOS) or Chrome (Android)
2. Tap the share button
3. Select "Add to Home Screen"

## Files

- `index.html` - Main app structure
- `styles.css` - Mobile-optimized styling
- `workouts.js` - Your 3 workout programs
- `app.js` - All app functionality
