# Dice Game Picker

A fun, interactive React application where kids can roll a dice to discover exciting games and activities to play!

## Features

- **Interactive Dice Rolling**: Click to roll a virtual dice with fun animations
- **6 Game Categories**: Each dice number (1-6) corresponds to a different category of activities
- **30 Child-Friendly Games**: 5 games per category, all safe and fun for kids
- **Re-roll Option**: Don't like the game? Try another one from the same category!
- **Roll History**: Keep track of your recent rolls
- **Beautiful Design**: Colorful, engaging interface designed for children
- **Responsive**: Works great on desktop, tablet, and mobile devices

## Game Categories

| Dice | Category | Description |
|------|----------|-------------|
| 1 | Active Games | Get moving with Simon Says, Freeze Dance, Tag, and more! |
| 2 | Creative Activities | Express yourself with drawing, origami, finger painting |
| 3 | Brain Games | Challenge your mind with I Spy, 20 Questions, Memory Match |
| 4 | Outdoor Adventures | Explore nature with Hide and Seek, Scavenger Hunts, Bug Safari |
| 5 | Team Games | Play together with Charades, Telephone, Relay Races |
| 6 | Quiet Activities | Calm down with Story Time, Puzzles, Building Blocks |

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Navigate to the dice-game-picker directory:
   ```bash
   cd dice-game-picker
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## How to Play

1. Click the "Roll the Dice!" button or click directly on the dice
2. Watch the dice spin and land on a number (1-6)
3. Discover your randomly selected game or activity
4. If you want a different game from the same category, click "Try another..."
5. Have fun playing!

## Building for Production

```bash
npm run build
```

This creates an optimized build in the `build` folder.
