# Split repo handoff

Three git bundles ready to push to the new `alexanderrko/*` repos, plus a
one-shot push script. Generated by Claude Code on `claude/revenue-dashboard-reports-JmxmR`.

## Files

| File | Size | Commits | Target repo |
|---|---|---|---|
| `nsw-auction-tracker.bundle` | 32K | 4 | `alexanderrko/nsw-auction-tracker` (empty, fast-forward) |
| `breathing-exercises.bundle` | 12K | 2 | `alexanderrko/breathing-exercises` (empty, fast-forward) |
| `portfolio-tracker.bundle` | 156K | 21 | `alexanderrko/portfolio-tracker` (force-push, overwrites placeholder commit) |
| `push-splits.sh` | 1.3K | — | One-shot pusher |

## Use

On your local machine (anywhere you have SSH set up for GitHub):

```bash
# 1. Clone the handoff branch (or download the .handoff/ folder via GitHub's UI)
git clone -b claude/handoff-split-bundles git@github.com:alexanderrko/alexanderrko.git handoff
cd handoff/.handoff

# 2. Run the pusher
chmod +x push-splits.sh
./push-splits.sh
```

The script clones each bundle into a temp dir, sets the `git@github.com:alexanderrko/<name>.git`
remote, and pushes — force-pushing only `portfolio-tracker` to overwrite its
auto-generated initial commit.

## Cleanup after pushing

Delete this handoff branch from GitHub once the three target repos have your code:

```bash
git push origin --delete claude/handoff-split-bundles
```
