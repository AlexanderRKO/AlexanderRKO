# Split repo handoff

Three git bundles ready to push to the new `alexanderrko/*` repos, plus a
one-shot push script. Generated by Claude Code on `claude/revenue-dashboard-reports-JmxmR`.

## Files

| File | Size | Commits | Target repo |
|---|---|---|---|
| `nsw-auction-tracker.bundle` | 32K | 4 | `alexanderrko/nsw-auction-tracker` (empty, fast-forward) |
| `breathing-exercises.bundle` | 12K | 2 | `alexanderrko/breathing-exercises` (empty, fast-forward) |
| `portfolio-tracker.bundle` | 156K | 21 | `alexanderrko/portfolio-tracker` (force-push, overwrites placeholder commit) |
| `push-splits.sh` | 1.3K | — | One-shot pusher |

## Use

On your **local machine** (not the Claude sandbox).

### One-time auth setup

```bash
# 1. Install gh CLI (skip if already installed)
#    macOS:   brew install gh
#    Windows: winget install --id GitHub.cli
#    Linux:   see https://cli.github.com/

# 2. Log in as the account that owns the three target repos
gh auth login
#   -> GitHub.com  |  HTTPS  |  Login with a web browser
#   -> sign in as alexanderrko

# 3. Verify
gh auth status
#   -> "Logged in to github.com account alexanderrko"

# 4. Wire git to use gh's token for HTTPS pushes
gh auth setup-git
```

### Run the pusher

```bash
# Clone the handoff branch (HTTPS — no SSH keys needed)
git clone -b claude/handoff-split-bundles \
  https://github.com/AlexanderRKO/AlexanderRKO.git ~/handoff
cd ~/handoff/.handoff

chmod +x push-splits.sh
./push-splits.sh
```

The script clones each bundle into a temp dir, points it at
`https://github.com/alexanderrko/<name>.git`, and pushes — force-pushing only
`portfolio-tracker` to overwrite its auto-generated initial commit. It also
preflights that gh is installed, authed, and logged in as `alexanderrko`.

## Cleanup after pushing

Delete this handoff branch from GitHub once the three target repos have your code:

```bash
git push origin --delete claude/handoff-split-bundles
```
